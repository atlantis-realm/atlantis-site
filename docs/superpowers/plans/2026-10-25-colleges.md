# The Three Colleges Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Alder (physics), Indigo (creative arts) and Saffron (earth sciences) their own palette,
roofs, signature buildings and landmarks, so the college ring reads as three places from the air.

**Architecture:**
- **Generator.** Everything is generated in `citygen.js`. A per-college config on the `park` district
  (`d.colleges`) is looked up by the cell's neighbourhood group (`park-0/1/2`).
- **Palette and roofs.** A material-palette seam lets `building()` and `roofTop()` take a college's
  material keys. Every other district keeps today's keys, byte for byte.
- **Signature forms.** These replace the plot buildings on college-use cells only.
- **Features in the bands.** The observatory, arcology and dye gardens sit inside the grove and orchard
  bands and clear trees through `o.noPlant`.
- **Blender.** `build_city.py` appends the new material keys with their colours, and builds a
  procedural pine distance tree.
- **Planner.** The planner gets a Colleges group and a colour for each college.

**Tech Stack:** Node 24 (CommonJS, `node:test`); Blender 5.2 Python through the Blender MCP; plain
HTML/JS planner (published artifact).

**Spec:** `docs/superpowers/specs/2026-10-25-colleges-design.md`

All paths are under `concept-assets/city/generators/` (abbreviated `gen/`), in the clone
`/run/media/dracky/e97d0aa9-5c45-460a-a682-b57cd6302030/Projects/atlantis-site-fork`, branch `wip-city`.

## Global Constraints

- **Single source.** Every college shape comes from `citygen.js`.
- **Seeded only.** Use `rng(key)` with keys starting `park|col|…`. Never `Math.random`.
- **Nothing outside the college ring changes.** Lots, objects and instances whose district is not
  `park` stay byte-identical to the Task 1 baseline. Skywalk objects are exempt, because they read
  park cells.
- **Materials.** New `MAT` keys are appended at the end of `MAT` in `build_city.py`, because the
  material index is the key's position. `MAT` stays a single dict literal at column 0, since the test
  regex parses it.
- **Colours in code.** Every new material gets its colour in code, through an idempotent setter called
  before `MATS` is built.
- **Occupation stays.** Cell uses, ring radii and band radii don't change. Signature forms go on
  college-use cells only. Every building in a college's sector takes that college's palette and roof
  kind.
- **Saffron's orchard band gets no buildings or features.** Its tree count there stays the same as the
  baseline.
- **Banned words.** No user-facing text says "island", "temple", "spire", "Circular Manhattan" or
  "Sable Heights".
- **Heights.** Every college lot's top stays below `o.lantern.heart[1]`, even with
  `core.lantern.height = 300`.
- **Tests.** Run from `gen/` with `node --test "test/*.test.js"`. Helpers live in `test/helpers.js`.
- **Commits.** After each task, commit with explicit paths only. Never use `git commit -am`, because
  `Atlantian_plaza_blockout-v01.blend` has an unrelated change. Never push. `.blend` files go through
  Git LFS.

## Review Focus

1. **A store doc older than `colleges`.** `generate()` builds the default colleges and never throws.
   (Task 1)
2. **Neighbourhoods disabled.** With `neighbourhoods.enabled: false`, `o.nb` is null. The group falls
   back to `floor(cell.k / 2)`, and the colleges still get their styles. (Task 1)
3. **Spoke count 5 or 8.** The group count changes. Groups beyond the three configured colleges keep
   today's style, and a college whose group doesn't exist is skipped. Each landmark exists at most once,
   and nothing throws. (Tasks 1 and 3–6)
4. **`grow: false`.** That college puts no lots, features or prims in its grove or orchard band.
   (Tasks 3 and 6)
5. **Lantern at 300 m.** No college lot or landmark tops the heart. (Tasks 3, 5 and 6)

  | `copper` | `MAT_AP_Verdigris` | (0.30, 0.55, 0.47) |

  | `plaster_c` | `MAT_AP_PlasterTeal` | (0.30, 0.55, 0.55) |
  | `rooftile` | `MAT_AP_RoofTile` | terracotta (0.55, 0.20, 0.10) |
  | `canvas` | `MAT_AP_Canvas` | (0.85, 0.20, 0.18) |
  | `dye` | `MAT_AP_DyeBed` | (0.35, 0.15, 0.55) |
